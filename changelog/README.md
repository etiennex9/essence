# Changelog entries

One file per change that users would notice, named freely (`draggable-bottom-sheet.json`), in English and French:

```json
{
  "en": "On phones, drag a station’s panel up to see more of it, or down to close it.",
  "fr": "Sur téléphone, faites glisser le panneau d’une station vers le haut pour l’agrandir, ou vers le bas pour le fermer."
}
```

Don't write a date: the entry is dated by the day it lands on `main`. Only an entry written after the fact gets
`"date": "YYYY-MM-DD"`, and so does a renamed one, which would otherwise move to the day of the rename.
See the README's [Versions](../README.md#versions) section.
